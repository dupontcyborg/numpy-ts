### equal

Test element-wise equality. Inputs are broadcast together.

```typescript
function equal(x1: NDArray, x2: NDArray | number): NDArray
```

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `x1` | `NDArray` | -- | First input array. |
| `x2` | `NDArray` | -- | Second input array. |

**Returns:** `NDArray` -- Boolean array where each element is `true` where `x1 == x2`.

```typescript
import * as np from 'numpy-ts';

const a = np.array([1, 2, 3]);
const b = np.array([1, 0, 3]);

const result = np.equal(a, b);
// array([true, false, true])
```

### allclose

Return `true` if all elements of two arrays are equal within a tolerance.

```typescript
function allclose(a: NDArray, b: NDArray | number, rtol?: number, atol?: number): boolean
```

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `a` | `NDArray` | -- | First input array. |
| `b` | `NDArray \| number` | -- | Second input array. |
| `rtol` | `number` | `1e-5` | Relative tolerance. |
| `atol` | `number` | `1e-8` | Absolute tolerance. |

**Returns:** `boolean` -- `true` if `|a - b| <= atol + rtol * |b|` for all element pairs.

```typescript
import * as np from 'numpy-ts';

np.allclose(np.array([1.0, 1.00001]), np.array([1.0, 1.0]));
// true

np.allclose(np.array([1.0, 1.1]), np.array([1.0, 1.0]));
// false

np.allclose(np.array([1.0, 1.1]), np.array([1.0, 1.0]), 0.2);
// true (increased rtol)
```

### isclose

Return a boolean array where each element is `true` if the corresponding elements of `a` and `b` are equal within a tolerance.

```typescript
function isclose(a: NDArray, b: NDArray | number, rtol?: number, atol?: number): NDArray
```

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `a` | `NDArray` | -- | First input array. |
| `b` | `NDArray` | -- | Second input array. |
| `rtol` | `number` | `1e-5` | Relative tolerance. |
| `atol` | `number` | `1e-8` | Absolute tolerance. |

**Returns:** `NDArray` -- Boolean array of element-wise closeness results.

```typescript
import * as np from 'numpy-ts';

const result = np.isclose(np.array([1.0, 1.00001, 1.1]), np.array([1.0, 1.0, 1.0]), 1e-5, 1e-8);
// array([true, true, false])
```

### array_equal

Return `true` if two arrays have the same shape and all elements are equal.

```typescript
function array_equal(a: NDArray, b: NDArray, equal_nan?: boolean): boolean
```

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `a` | `NDArray` | -- | First input array. |
| `b` | `NDArray` | -- | Second input array. |
| `equal_nan` | `boolean` | `false` | If `true`, `NaN` values compare equal. |

**Returns:** `boolean` -- `true` if both arrays have the same shape and identical elements.

```typescript
import * as np from 'numpy-ts';

np.array_equal(np.array([1, 2, 3]), np.array([1, 2, 3]));
// true

np.array_equal(np.array([1, 2, 3]), np.array([1, 2, 4]));
// false

np.array_equal(np.array([1, 2]), np.array([[1, 2]]));
// false (different shapes)
```

### array_equiv

Return `true` if two arrays are broadcastable to the same shape and all elements are equal after broadcasting.

```typescript
function array_equiv(a: NDArray, b: NDArray): boolean
```

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `a` | `NDArray` | -- | First input array. |
| `b` | `NDArray` | -- | Second input array. |

**Returns:** `boolean` -- `true` if the arrays are shape-compatible (broadcastable) and all corresponding elements are equal.

```typescript
import * as np from 'numpy-ts';

np.array_equiv(np.array([1, 2, 3]), np.array([1, 2, 3]));
// true

// Broadcasting: [1] is equivalent to [1, 1, 1]
np.array_equiv(np.array([1]), np.ones([3]));
// true

np.array_equiv(np.array([1, 2]), np.array([1, 3]));
// false
```
